# PVSyst inputs

These files were prepared with PVSyst 8.0.11 for the apple agrivoltaics workflow. `PVSyst_Variant_Download.py` currently runs variants `VCL`, `VC7`, and `VC8`; all 18 `Tracking Apple Panels_Project.VC*` files are archived for completeness.

The files are preserved without modification. Some PVSyst variant files contain historical absolute paths to weather files and historical conversion-format names. New simulations should use the paths configured by `PVSyst_Variant_Download.py` and the `APPLE_APV_DATA_ROOT` environment variable.

See `PVSyst_asset_manifest.tsv` for exact relative paths, file sizes, and SHA-256 checksums.
